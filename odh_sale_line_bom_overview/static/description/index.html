Sale Order Line BOM Overview

In standard Odoo, checking a product's Bill of Materials (BOM) from a Sales Order requires multiple steps—opening the product, navigating to BOMs, selecting the correct BOM, and then opening the BOM overview. This interrupts the sales workflow and consumes valuable time.

To solve this, we developed Sale Order Line BOM Overview, a module that brings BOM visibility directly into the Sales Order line, allowing users to access BOM details instantly without leaving the Sales Order.

Key Features

  • BOM selection directly on Sales Order lines
  • Automatically loads all related BOMs when a product is selected
  • Auto-selects the BOM if the product has only one available BOM
  • Smart BOM Overview button that appears only after a BOM is selected
  • One-click access to the complete BOM structure in a new page
  • Eliminates unnecessary navigation through Product and Manufacturing menus
  • Improves coordination between sales, manufacturing, and planning teams

How It Works

  • Select a product on the Sales Order line
  • All related BOMs are loaded automatically
  • If only one BOM exists, it is set by default
  • Click BOM Overview to instantly open the BOM structure

Why Use This Module?

  • Speeds up Sales Order processing
  • Provides better visibility for production planning
  • Reduces user clicks and navigation
  • Delivers a cleaner and more intuitive user experience
  • Ideal for manufacturing-driven businesses
